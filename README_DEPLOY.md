# Art Slicer Mobile — Safari Web App

This is a static website. No backend is required.

## GitHub Pages
1. Create a GitHub repository, for example `art-slicer-mobile`.
2. Upload these files to the repository root:
   - index.html
   - manifest.webmanifest
   - sw.js
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose `main` and `/ (root)`.
6. Save.
7. Open the HTTPS Pages URL in Safari.
8. Use Share → Add to Home Screen if desired.

## Cloudflare Pages
1. Create a Pages project.
2. Deploy this folder as a static site.
3. No build command is required.
4. Open the generated HTTPS URL in Safari.

## Privacy
The site itself loads from the host.
Selected images are processed locally in Safari using browser APIs.
This build contains no image-upload endpoint.

## Recommended iPhone settings
- 150–200 DPI for large artwork
- Letter 8.5 × 11
- 5–7 mm overlap
- mirror enabled for gel transfer
